# Copy to ~/.cursor2openai/model-filter.txt to hide models from the model list.
# One regular expression per line. It must match the whole model name; case is ignored.
# Hidden models still work when a request names them.
#
# This example keeps only the newest version of each provider (as of 2026-10-08)
# and hides every older version, whatever the model line.
# Update the version numbers when a provider releases a newer model.

# Anthropic: keep Claude 5.5 (opus, sonnet, haiku).
# Hides Claude 4.x, Claude 5 and Claude 5.1-5.4 (including Fable 5.1).
claude-4.*
claude-[a-z]+-4-.*
claude-[a-z]+-5(-[a-z].*)?
claude-[a-z]+-5-[0-4](-.*)?

# OpenAI: keep GPT-5.6 (sol, luna, terra).
# Hides GPT-4, GPT-5 and GPT-5.1-5.5 (including codex, mini and nano).
gpt-4.*
gpt-5(\.[1-5])?(-.*)?

# Google: keep Gemini 3.8. Hides Gemini 3 and 3.1-3.7 (including 3.1 Pro).
gemini-3(\.[1-7])?-.*

# xAI: keep Grok 4.7. Hides Grok 4.0-4.6, including Cursor's own Grok builds.
(cursor-)?grok-4(\.[0-6])?(-.*)?

# Moonshot: keep Kimi K3. Hides Kimi K2.x.
kimi-k2.*

# Variants: hide every "fast" and "xhigh" variant of any model, for example
# gpt-5.6-sol-high-fast, claude-opus-5-5-xhigh and claude-opus-5-5-thinking-xhigh.
.*-fast(-.*)?
.*-xhigh(-.*)?

# Cursor's automatic model choice.
auto

# Anthropic and OpenAI: hide the "max" effort variants, for example claude-opus-5-5-max,
# claude-haiku-5-5-thinking-max and gpt-5.6-sol-max.
(claude|gpt)-.*-max(-.*)?
